Vidence 是一款 AI 视频学习助手，帮你边看视频边提问、整理重点、保存每个视频的学习记忆，之后查找和复习。

## 下载浏览器插件

**下载下方 Assets 中的 `Vidence-Browser-Extension.zip`。** 这是独立浏览器插件，直接使用你已经安装的桌面 Chrome / Edge。不要下载 Source code，那个是开发源码。

完整解压后，Windows 双击“安装到浏览器.cmd”，按提示开启开发者模式、加载扩展。macOS / Linux 在扩展管理页直接加载包内的 `extension` 文件夹。浏览器首次安装需要用户亲自确认。[查看详细安装步骤](https://github.com/lby749/Vidence/blob/main/docs/browser-extension.md)。

## 本次更新

- 浏览器插件独立分发，不含桌面程序、浏览器内核、模型权重，也不要求 Python / Node.js。
- 侧栏复用助手与模型选择器，可以在栏内搜索和切换模型；打开侧栏尊重已保存的 API 选择。
- 学习栏支持 × 与 Esc 关闭，重新打开由用户操作；关闭学习栏不会停止正在记录的课程。
- 支持填写 API Key 后获取可用模型、测试连接、配置问答与摘要；可自行选择模型。
- 保留按视频隔离的记录、笔记、聊天、长期记忆和检索，以及按需读图、离线功能档位、语言设置、更新提醒与反馈入口。
- 包内附安装引导、使用说明、MIT 与第三方原始声明。`.sha256` 文件用于核对下载完整性。

已有用户请保留原浏览器和插件安装目录，覆盖文件后点“重新加载”，不要先卸载插件，以免删除学习资料。建议先导出备份。

原生桌面版仍在完善，本次仅发布插件。包内可选离线功能的推理代码不是浏览器内核；模型需要用户选择后另外下载。受保护课程、跨域播放器与平台变化可能限制字幕或画面采集，不能保证所有平台与账号流程均可用。

## 测试与反馈

发布流水线从全新源码目录在 Linux、Windows 托管机器安装开发依赖，检查类型、145 项单元测试、构建、最终 ZIP 解压后加载、字幕记录与检索、侧栏关闭、API 模型发现与切换、设置、更新和反馈。Windows 另用系统 PowerShell 验证安装与重复更新，测试不会打开用户日常浏览器。
