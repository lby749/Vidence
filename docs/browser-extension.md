# Vidence 浏览器插件

Vidence 帮你在浏览器看视频时提问、整理重点，并把每个视频的笔记与学习记忆分别保存，之后检索和复习。

## 下载与安装

到 [Releases 下载页面](https://github.com/lby749/Vidence/releases)选择下面一种文件，不必两个都下载。不要下载 Source code，那个是开发源码。

### Windows 安装引导（推荐）

1. 下载 **Vidence-Extension-Setup-Windows.exe**，直接双击，无需解压、CMD、管理员权限或安装 Python / Node.js。适用于 Windows 10 / 11，使用系统已有的 .NET Framework。
2. 选择 Edge 或 Chrome，点击“安装并打开浏览器”。程序把自带的插件放到固定目录，提供文件夹路径并打开扩展管理页。
3. 在浏览器开启“开发人员模式 / 开发者模式”，点击“加载解压缩的扩展 / 加载已解压的扩展程序”，粘贴安装引导提供的路径并选择文件夹。
4. 刷新视频网页，点击视频旁的 Vidence 按钮开始使用。右侧学习栏可以通过 × 关闭。

安装引导只准备插件文件，首次加载仍由你在浏览器中确认。尚未上架扩展商店，不会修改企业策略或直接写入浏览器配置来强装。EXE 当前未附商业代码签名，Windows 可能显示未知发布者；也可选择纯插件 ZIP 手动安装。

### 纯插件 ZIP（手动安装）

下载 **Vidence-Browser-Extension.zip**，完整解压。直接打开 `edge://extensions/` 或 `chrome://extensions/`，开启开发者模式，选择“加载已解压的扩展”，加载**直接包含 `manifest.json` 的文件夹**。本包没有 EXE、CMD、PowerShell 或安装器，解压后就是插件文件，Windows / macOS / Linux 均可使用支持的桌面浏览器手动加载。

手动安装后请保留该目录，浏览器会继续读取它。Firefox 与手机浏览器不在本次范围内。插件和安装引导都不附带浏览器内核、桌面软件或模型权重。

### 更新并保留资料

- 使用此前 Windows 安装引导固定目录的用户：运行新 EXE，然后在扩展管理页对原插件点击“重新加载”，再刷新视频网页。无需先卸载。
- 此前手动选过其他目录的用户：使用纯插件 ZIP，把新文件放回**原来包含 `manifest.json` 的目录**并重新加载。改用另一目录可能形成另一份扩展，不会自动迁移原浏览器的学习资料。
- 建议先在视频库导出备份。学习资料在浏览器扩展存储里，安装器只替换自己的代码目录，不访问浏览器资料库。

## 连接 AI 与选择模型

打开视频库的“设置 → AI 助手”，在“用 API Key 连接”选择服务并粘贴 Key。点“一键连接并配置”会获取模型目录、发送一句简短测试消息并配置问答与摘要；“自己选择模型”可先获取目录，再选模型。

在视频右侧学习栏点击助手名称或模型名称，可以在栏内搜索、切换已连接的助手与模型。API 路线不需要本机智能体。OpenCode Go、DeepSeek Harness、Codex CLI、Claude Code 是可选连接，需要你另行安装对应工具并运行本机桥接，不包含在插件包中。

## 使用与资料保存

- 点击“开始记录”才开始整理当前视频。软字幕可直接读取；画面 OCR、语义检索等离线能力按档位下载模型后启用。
- 字幕先概括，再用于问答；可按需要核对原文和原图。允许读取图片需要全局设置与本次提问同时同意。
- 视频库里可按视频查看笔记、聊天、截图与长期记忆，选择多个视频分别整理。记录与检索以视频隔离。
- 学习资料保存在当前浏览器的扩展存储中。建议定期导出备份，卸载扩展、清理扩展存储或更换浏览器不会自动迁移资料。
- 更新时使用同一目录覆盖插件文件，在扩展管理页点“重新加载”并刷新视频网页。已加载的同一路径可以保留原扩展身份与资料；不要先卸载旧插件。
- 新版本提示会打开 Releases 下载页面，不会静默安装新包；反馈入口在“设置 → 应用更新”。

## 本次范围与限制

面向桌面 Chrome / Edge 的普通网页视频。独立原生桌面软件与本地 MP4 播放器不在此包内；受保护课程、跨域播放器、画面禁止采集、平台字幕变化仍可能导致部分功能不可用。未将 Linux 无界面测试写成 macOS、所有平台账号或真实模型全量验收。
