# 原生桌面与浏览器插件

Vidence 帮你边看视频边提问、整理笔记，并分别保存每个视频的学习记忆。浏览器插件直接配合已有浏览器使用；原生桌面用于本地视频和课程窗口，两者分别下载、安装和保存资料。

## 两种使用方式

| | 原生桌面 | 浏览器插件 |
| --- | --- | --- |
| 界面 | Qt Widgets 原生控件，含可收展的右侧学习栏 | Chrome / Edge 内的扩展侧栏 |
| 播放 | Qt 原生播放器，或挂靠已有课程窗口 | 原网页播放器 |
| 浏览器内核 | 不捆绑 Chromium / QtWebEngine | 使用用户已有浏览器，不附带浏览器 |
| 数据 | 本机 SQLite，按视频隔离 | 原浏览器 IndexedDB，按视频隔离 |
| AI | OpenCode Go / DSH、Codex / Claude CLI、OpenAI兼容及Anthropic API | 保留浏览器端已有渠道 |
| 图片 | 本次授权后读取原图，记录实际图片ID和时间 | 本次授权后读取原图 |
| 离线功能 | 系统OCR；中/高档按需下载量化检索模型与CPU/Vulkan/Metal组件 | 按档位下载浏览器推理资源 |

插件使用 API 时不要求先安装桌面软件；使用本机智能体时仍需配置智能体和桥接。浏览器首次安装扩展需要用户在管理页亲自确认。

桌面主界面不使用 WebView。用户主动选择“应用内网页”时才借用系统已有 WebView2 显示课程网站；系统缺少此组件时仍可用本地视频、外部浏览器和课程窗口，不为此捆绑或自动安装浏览器内核。

## 原生版已有流程

- 来源选择在右侧学习栏内展开；取消文件选择保留当前视频和草稿。
- 本地视频保留原始解码分辨率和帧率，学习采样按低频独立执行，不逐播放帧JPEG编码。
- 按视频保存文字、原图、笔记、聊天、长期记忆与版本。切换视频停止旧记录，草稿分别保存。
- 原文先概括，再进入初始问答上下文；按需工具读取本视频原文和原图。选择某份笔记时还限定时间段。
- 图片筛选读取真正原图，讲师与板书同框可保留；纯讲者、片头片尾默认隐藏，原图可恢复。
- 语言支持简体中文、繁体中文和英文；智能体和服务商按语言调整顺序，用户视频标题不翻译。部分动态提示仍需继续补齐翻译。
- API服务商可选，一键连接获取模型目录；显示名称与实际模型ID分开保存。密钥不随学习资料导出。
- 自动检查公开版本元数据，提供独立下载页和反馈入口，不发送学习数据或凭据。

## 已完成的本机检查

2026-11-12：145项前端单元测试、29项Python检查、三语言原生UI的聊天/草稿隔离、取消选源、收展及模型ID保存通过。

真实 OpenCode Go / DeepSeek V4.1 Flash 对数学原图、禁用图片、换成Excel图的三个对照通过。两段真实B站缓存原媒体在原生播放器中解码并保存1280×720与640×360原图，系统OCR、概括、分别生成长期记忆及同视频问答已跑通。这里不把原媒体缓存重放称为登录账号网页端完整验收，也不把一个片段的OCR结果称为整课准确率。

搬移后的冻结桌面检查包在目标PATH仅System32时，通过原生学习栏构造、系统英文OCR、包内Node桥接和720p H264实际解码（226帧、3733ms、两次不同像素取样）。这是解码证明，不是显示器最终呈现帧率或物理空白Windows证明。

原生检查包约99,830,480字节，独立插件检查包25,524,004字节；旧合并BETA.3包359,145,894字节。检查包没有浏览器内核、模型权重、用户库、登录态或密钥；桌面不附带扩展和离线推理运行时。最终发行大小以通过云端验收的发布资产为准。

离线模型与计算组件按固定摘要验证后安装，实际Vulkan推理与设备错误后自动CPU回退已通过；这不代表AMD/Apple实机已测试。

## 当前限制与发布状态

新架构仍在独立分支进行云端验收，尚未覆盖或替换已发布BETA.3。原生版暂未迁移Notion同步、AI网页渠道、浏览器字幕适配及全部旧聊天的自动迁移；浏览器插件保留原有对应功能。旧IndexedDB保留，可从旧版导出后导入原生库。

系统OCR会误识小字、低清画面和公式，原文与AI笔记都可能有错。摘要应标明不确定性，不能把错误或推测固化成知识；重要公式和表格请允许读取原图后核对。窗口采集时间为“记录时间”，不能冒充课程媒体进度。

Android、TTS和听视频ASR尚未实现；iPhone暂缓。物理空白Windows、缺少WebView2、全部平台账号与网页全屏、AMD/Apple实机仍需分别验证。
