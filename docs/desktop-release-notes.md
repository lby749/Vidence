# Vidence Desktop 0.4.4

Vidence 是 AI 视频学习助手，帮助你边看视频边提问、整理重点，并分别保存每个视频的笔记和长期记忆，以后继续查找和复习。

## 下载与使用

下载本页 Assets 中的 **Vidence-Desktop-Windows-x64.zip**，完整解压，双击 **一键启动.exe**。支持 Windows 10 / 11 x64，无需安装 Python、Node.js 或开发工具。可用旁边的 `.sha256` 文件核对下载完整性。

这是独立原生桌面版，主界面、播放器与右侧学习栏均使用 Qt Widgets，**不捆绑 Chromium、QtWebEngine、浏览器插件或模型权重**。浏览器插件请单独下载 [0.4.1 插件发行版](https://github.com/lby749/Vidence/releases/tag/v0.4.1)。EXE 暂未签名，Windows 可能显示未知发布者提示。

## 可以做什么

- 打开本地视频，或选择已经打开的课程窗口，展开旁边的学习栏。
- 暂停、拖动进度、调节音量、全屏播放；侧栏可以收起、关闭并重新打开。
- 在提问栏直接切换助手与模型。API Key 连接可获取可用聊天模型，支持填写完整的兼容接口地址。
- 记录文字和画面、整理重点，按视频分别保存聊天与长期记忆。允许本次读图后，问答可读取原图并返回画面引用。
- 按需下载离线检索模型与计算组件；优先尝试可用 GPU，失败可退回 CPU。
- 桌面版独立检查更新，并提供问题反馈入口。

设置中的“应用内网页”可借用系统已有 WebView2 打开课程网站；系统缺少此组件时，请在自己的浏览器播放，再关联课程窗口。桌面包不会安装或捆绑浏览器内核。

### 0.4.4 更新

新增云端冻结成品的完整学习流程验收，直接运行最终 ZIP 中的 EXE：选视频、记录及系统 OCR、知识图筛选、摘要、长期记忆、聊天和检索隔离、选择性导出导入，再启动第二个进程验证持久化和继续问答。使用真实 Qwen3-VL-4B Q4 模型进行有图、禁图、换图对照；测试模型只在云端临时使用，不进入下载包。

修复升级后沿用旧版本更新缓存的问题，保留用户的自动提醒偏好。

### 暂停窗口记录

首次采集已暂停的课程窗口时，系统可能暂不提供首帧。现在会明确提示保持窗口可见并播放片刻；取得画面后可继续记录。已经取得的静止画面可以手动保存，自动采样仍跳过过旧画面，避免重复记录。此修正不代表可以读取被平台保护或系统拒绝采集的内容。

## 验证与边界

发布前进行源码检查、隔离数据测试、实际原生窗口的播放及侧栏操作测试，以及云端构建和另一台 Windows runner 的冻结成品检查。成品检查限制 PATH，使系统 Python / Node.js 不可用；这不是物理空白 Windows 或全部硬件的证明。详细记录见[验证说明](verification.md)。

系统 OCR 可能误识小字和公式，AI 笔记也可能出错；重要内容请核对原图。受保护课程、网页全屏、不同账号和采集权限须按实际平台验证。桌面版暂未迁移 Notion 同步、AI 网页渠道和浏览器字幕适配；原浏览器资料不会自动合并。Android、TTS、听视频 ASR 尚未实现，iPhone 暂缓；AMD / Apple 实机尚未验收。
