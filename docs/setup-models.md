# 模型和 AI 助手怎么设置

普通使用者从“设置”进入，只需按需要完成下面的选择。

Windows 发布包自带所需程序，不需要自行安装 Python、Node、npm。完整解压后双击“一键启动.exe”。缺少网页播放组件时，启动器用随包的微软安装程序联网补齐；断网可先用本地视频。插件安装在同一个启动器中，使用预编译文件，首次仍需在 Edge/Chrome 确认加载；不改变浏览器登录和安全策略。

在右侧学习栏点“来源”，在展开的小面板中选择本地文件、网页课程或已打开的课程窗口。应用内网页使用原生播放器，可直接操作网页底部控件和全屏；选择外部浏览器时再选择其窗口。识别范围预览只用于框选字幕，不冒充可操作的播放器。网页标题会从页面读取，平台按网址识别；手动名称不会被覆盖。

## 连接 AI 助手

已经使用 OpenCode Go、DeepSeek Harness、Codex 或 Claude Code，可以在“AI 助手”中连接。独立应用会尝试复用本机助手连接；浏览器扩展可粘贴“启动本地智能体”复制的连接码。

连接时从该助手获取可用聊天模型。当前这台电脑的 OpenCode Go 目录有 30 项，默认保留 DeepSeek V4.1 Flash；这是本机已配置目录，不能视作所有提供商的实时列表。只对实际调用过的模型作验收结论。

已经有 API 服务的用户，在“AI 助手”中选择服务、粘贴 Key，点击“一键连接并配置”。程序读取真实模型目录，发送一句简短测试消息，通过后同时配置问答与摘要；也可先点“自己选择模型”再连接。自建接口可填写自己的地址。侧栏内可切换智能体、API 服务和聊天模型，搜索及分组选择；不弹出独立选择窗口。API 问答和摘要也可在高级选项分别选用不同模型。Key 不进入视频记忆导出文件。

## 界面语言与排序

“学习偏好 → 界面语言”提供跟随系统、简体中文、繁体中文、English。旧用户保留中文默认，新用户可跟随系统；其他系统语言回退英文。简体中文优先国内常用工具和平台，英文/繁体优先国际常用项。排序不改用户选中的智能体、服务、模型或课程。界面字典本地运行，不调用 AI 翻译；回答与摘要仍有独立的12种语言选项。视频名称、字幕、聊天正文和草稿不随界面语言改写。

## 选择占用档位

在“离线功能”中选择无占用、低占用、中占用或高占用，再点“下载并启用”。应用按选择准备资源，不要求用户认识模型名。新用户默认不启用本地模型，保留已有用户的设置。

| 档位 | 扩展资源 | 独立应用资源 | 用途 |
| --- | --- | --- | --- |
| 无占用 | 0 MB | 0 MB | 不加载本地 AI 模型；已有记录、关键词检索与已连接的 AI 服务仍可用 |
| 低占用 | 21.5 MB | 21.5 MB | 画面文字识别，降低稳态识别频率 |
| 中占用 | 46.1 MB | 约 257.9 MB | 画面识别 + 语义检索 |
| 高占用 | 342.0 MB | 约 553.8 MB | 画面识别 + 语义检索 + 检索精排 |

独立应用的语义检索使用 EmbeddingGemma 300M Q4_K_M 原生运行时，优先 Windows Vulkan（NVIDIA/AMD）或 macOS Metal，失败退回 CPU；扩展仍使用原有 BGE。当前真实硬件只验收了 Windows RTX5070 Vulkan 与 CPU，AMD/苹果硬件尚未实机验收。模型文件空间与运行内存是不同指标；公开固定样本比较见 docs/resource-usage.md。

“无占用”不是整台应用零 CPU/内存。档位控制本地 AI 功能，应用运行时与已连接的助手仍有基础占用。AI 回答沿用已连接的服务，不下载聊天大模型。实际运行开关和稳态识别频率随档位改变；已有本地模型会在切档时卸载。降档保留已下载文件，升级复用已验证的缓存。独立应用正在记录时选择无占用，会保存当前记录并停止播放与采集；浏览器仍可记录已有字幕。

已有可读字幕的网页可以直接记录，关键词检索也无需下载模型。推理时只读取已下载缓存，不自行开始下载。下载显示进度，可以取消；已完成的文件保留，再点下载继续缺失的文件。每个文件按固定大小和 SHA-256 核验，校验不通过不安装。

模型不进入发布包。WASM、Qt、Node 等程序运行时仍随应用提供。开发者保留的 public/models 和 public/ocr 只是本机测试资源，WXT 构建会将它们排除。

下载来源为 PaddleOCR 官方对象存储与 Hugging Face 镜像。嵌入、重排下载链接固定到已核对的上游提交，文件校验记录在 src/models/model-manifest.json。

## 学习偏好与语言

可以选择回答及摘要的语言：简体中文、繁体中文、English、Español、日本語、한국어、Français、Deutsch、Português、Русский、العربية，或跟随内容和问题。字幕原文保留原语言，不把翻译当作视频原话。

风格有清晰自然、简洁直接、耐心讲解、考试复习、深入分析、轻松交流六种。选择会写进 API、原生助手、网页辅助、手动交接和记忆整理的内置提示词，记忆工具重读问题时也携带当前偏好；历史回答的语言不会覆盖当前选择。当前问题明确要求其他语言或展开时可覆盖默认表达偏好。风格不会改变证据来源、引用和未记录内容的边界。

## 量化与准确性

语义检索使用 Q8 版 bge-small-zh-v1.5，精排使用 INT8 版 bge-reranker-base；已读取实际 ONNX 张量与量化算子核对，见 artifacts/quantization-audit.json。OCR 目前保留 PP-OCRv5 mobile 的非量化轻量版，不把它标作量化模型。

本次离线小样本：5 张受控文字图的归一化字符准确率 100%，中文主题检索命中 7/8，中英文精排命中 5/6。样本很小，不是公开基准、全课程准确率或与 FP32 的精度损失对照，完整输出见 artifacts/quantized-quality.json。模型来源与文件版本见 [量化文件目录](https://huggingface.co/Xenova/bge-small-zh-v1.5/tree/75c43b069aac4d136ba6bc1122f995fedcfd2781/onnx)和 [BGE 原始模型说明](https://huggingface.co/BAAI/bge-small-zh-v1.5)。

当前已经用真实英语 YouTube 视频验证英文字幕、长期记忆与英文问答。中文及中英混排画面 OCR 已实测；其他文字的图像识别模型尚未接入，不能把语言选项当作所有文字 OCR 均已支持。外语视频优先使用页面字幕或可读文本轨。

## 开发者构建

npm install 后直接 npm run build；prebuild 只从已安装依赖复制对应版本 WASM，不下载权重。

node scripts/fetch-models.mjs 仅用于准备本机开发测试资源，不是普通构建和终端用户安装的前置步骤。

npm run desktop 启动源码应用；npm run desktop:pack 生成 Windows 程序目录。运行模型自检需要保留本机测试资源，测试报告明确区分本机测试文件提供的下载与真实公网请求。
