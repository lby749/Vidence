# BETA 功能与入口审查

想确认 Vidence 能帮你播放视频、记录重点、提问或复习时，可以在这里按用途查看。每项都说明能做什么、依据是什么，以及还有哪些情况需要验证；整体介绍见[项目首页](../README.md)。

版本：0.1.0-beta.3。功能存在、隔离检查、真实模型、无界面UI、原生窗口与新云环境属于不同验证层。

| 主要用途 | 实现与证据 | 当前边界 |
| --- | --- | --- |
| 本地视频播放 | Qt原生输出；30/60和小数帧率、720p/1080p/4K H264窗口交付测试 | 其他编码、HDR、不同硬件未穷举 |
| 网页/客户端课程 | 自填URL、常见平台入口、现有浏览器/客户端窗口采集 | 平台入口不等于每个平台账号验收；受保护画面未保证 |
| 字幕与画面文字 | 可读字幕采集，本地OCR按占用档下载；不装OCR也能只记录高清画面 | 听视频ASR尚未实现；纯图片记录可问图，生成长期记忆仍需文字 |
| 候选图与知识筛选 | 135张真实原图分类，讲者/开场/片尾过滤、待确认和恢复 | 判断可能错；没有逐秒标注整段课程所有知识点 |
| 图片问答 | V4.1 Flash真图片、有图/无图/换图对照；引用可打开原图 | 小字抄读可能错；其他模型只列入目录不算通过 |
| 检索与来源 | 按视频/节点限制，关键词、可选语义与精排，画面摘要作线索 | 画面摘要不能替代原图引用 |
| 长期记忆 | 每视频独立，批量生成、编辑、锁定、版本与来源；已有隔离检查 | 未实现持续自动训练或跨设备云记忆 |
| 聊天与追问 | 侧栏与视频库复用同一聊天组件，按视频隔离草稿和历史 | 本机扩展与独立应用是各自本地数据库 |

| 离线占用与设备 | 档位按需下载，本地原生推理有GPU/CPU路径 | Apple/AMD实机未验收，模型权重不随包分发 |
| 多语言与风格 | 简/繁/英文界面，语言影响工具/渠道顺序；回答语言风格独立 | 少量动态计数字样待补齐；课程原文、用户标题不翻译；模型生成语言可能偏差 |
| 启动与浏览器安装 | 独立运行时，一键向导，浏览器确认加载 | 尚未上架商店，不是静默安装 |
| 本地数据 | 选择性导出/导入、视频删除、凭据排除 | Notion等真实账号同步未在本轮验收 |
| 应用更新提醒 | 每天匿名检查发布目录，版本比较、稍后提醒、手动检查、三语言界面均有回归 | 私有/未开放目录明确报不可用；下载由用户从发布页发起 |
| 问题反馈与建议 | 已确认仓库Issues开启；应用设置有入口，提供问题/建议表单 | 由用户自行提交，不自动附带课程、密钥或诊断数据 |
| 手机与语音 | 已列入计划 | Android、TTS、ASR未实现；iPhone暂缓 |

## 重复入口与用途

- 主界面来源选择和右侧来源弹层复用同一份选择内容，按当前状态只显示需要的入口，不再保留左侧重复面板。
- 侧栏聊天与视频库聊天复用VideoConversation，引用和图片授权一致；这两处是播放时/复习时的入口，不维护两套逻辑。
- “自动筛选”和“手动筛选”调用同一知识筛选函数；前者用于新记录，后者补处理已有视频，已完成的图不会重复请求。
- API一键连接与高级手填共用Settings。高级字段保留给自建兼容接口，普通流程先呈现一键设置。
- 长期记忆用于持久复习，片段摘要用于当前回答，原文与原图用于来源核验。不能用同一个名称混淆这三层。

## 本轮明确修复

图片被文字桥接丢弃、聊天固定禁图、图片额度重复计数、图片引用无原图入口、JSON语法错误中断、待确认图混入知识列表、英文侧栏弹层被裁剪、播放限流导致30帧变15帧、逐帧JPEG占用界面线程。

Vidence BETA.3的四项云端任务及GitHub发布已通过本轮检查，仓库已公开。应用、启动器、扩展与下载包统一使用Vidence；旧版需手动安装一次新版，原学习数据目录保留。真实缺少WebView2、Apple/AMD实机等尚未覆盖的范围与各证据层见verification.md。
