# 视频记忆助手 · BETA 测试版

把视频变成可复习、检索和提问的学习记忆。项目源码使用MIT，第三方组件保留各自声明。

## 开始使用

下载VideoMemory-Windows-x64.zip并完整解压，双击“一键启动.exe”。保留整个文件夹，无需安装Python、Node或npm。模型权重不在包内，需要离线功能时再按占用档位下载。

打开本地视频或网课来源，使用右侧学习栏开始记录；每个视频分别保存文字、知识画面、聊天和长期记忆。可连接已有OpenCode Go/DeepSeek Harness，或自己的API服务。

## 本版重点

- 原生视频输出，修复30帧被降成约15帧；60帧与23.976/29.97/59.94、720p/1080p/4K H264分别测试。
- 高清存档与轻量预览分开，持续动画可保存同场景代表图；不下载OCR也能只记录画面。
- 视觉助手筛选知识画面，讲者、开场和片尾单独过滤；待确认可恢复。真正传原图问答，引用能打开原图。
- 应用每天检查新版本，可查看说明、前往发布页、稍后提醒和关闭自动检查。界面支持简体、繁体和英文。
- 发布流程从干净源码构建，另一台Windows runner运行冻结程序实际解码生成片，并核对随包运行时和桥接。

## 已知范围

云端生成测试片、原媒体本机测试、真实模型测试和成品解码属于不同证据层；详见docs/verification.md和docs/feature-audit.md。GitHub托管runner预装工具和WebView2，不等于物理空白Windows，也未验证真实缺少WebView2时的安装。

Android、TTS和听视频ASR未实现，iPhone暂缓；Apple/AMD实机和所有课程平台账号尚未完整验收。纯图片记录可问图，长期记忆生成目前仍需文字。

原始课程、账号、浏览器配置、数据库、密钥和模型权重不在发行包。截图本地保存与上传授权分开。
