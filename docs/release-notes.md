# Vidence · BETA 测试版

**边看视频边提问，把学过的内容留下来。**

Vidence 是一款 AI 视频学习助手。看网课、教程或本地视频时，它可以帮你记录重点、整理笔记、解答疑问；看完以后，还能找到之前学过的内容，回到相关片段复习。

## 能帮你做什么

- 没听懂的概念或步骤，直接在视频旁提问。
- 把课程中的文字和重要画面整理成学习笔记，方便回顾。
- 允许读取截图后，结合公式、图表和板书讲解，并打开原图核对。
- 查找学过的内容，找到相关笔记、截图和视频时间。
- 选择视频分别积累学习记忆，在以后继续复习和追问。

## 开始使用

目前提供 Windows 应用和 Chrome / Edge 浏览器扩展，支持本地 MP4、网页视频与网课窗口。

1. 下载 `Vidence-Windows-x64.zip` 并完整解压，打开“一键启动.exe”。无需安装开发工具。
2. 打开本地视频，或选择课程网址、正在上课的窗口。
3. 在右侧学习栏开始记录和提问，结束后到视频库继续整理和复习。

使用 AI 功能前，在设置中连接你自己的 AI 服务；离线功能按需要下载。旧 BETA.1 / BETA.2 用户需手动安装一次新版，已有本机学习数据保留。

## 本版改进

- 应用和下载包统一使用 Vidence 名称，学习数据保留。
- 改善本地视频播放流畅度，保存更清晰的学习截图。
- 筛选知识画面，过滤纯讲者、开场和片尾；待确认的画面可以手动恢复。
- 图片问答附带可打开的原图引用，方便核对回答。
- 增加应用新版本提醒和问题反馈入口。

## 当前范围与反馈

学习数据默认保存在本机。连接云端 AI 后，按你的设置发送回答所需内容；截图本地保存与允许上传分开。发行包不包含用户课程、账号、密钥或模型权重。
