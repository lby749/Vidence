# Vidence · BETA.4 测试版

**边看视频边提问，把学过的内容留下来。**

Vidence 是一款 AI 视频学习助手。看网课、教程或本地视频时，可以帮你记录重点、整理笔记、解答疑问；看完以后，继续按视频查找和复习。

二者独立使用，按需要下载即可。桌面界面和学习侧栏使用原生控件，不附带 Chromium / QtWebEngine；插件直接使用你已有的浏览器。模型与离线计算组件都按需要下载，不放进安装包。

## 开始使用

- **桌面版**：完整解压，打开“一键启动.exe”。无需安装 Python、Node 或开发工具。打开本地视频，或选择正在上课的窗口，即可在右侧记录和提问；侧栏可以收起、展开，播放器可以全屏。
- **浏览器插件**：完整解压后运行“安装到浏览器.cmd”，选择 Chrome 或 Edge，按管理页提示完成安装。首次加载扩展需要你在浏览器亲自确认。其他桌面系统也可以在浏览器管理页加载包内 extension 文件夹。
- **AI 服务**：在设置中选择已有智能体，或选择服务商、填写自己的 API Key，点击连接即可获取可用模型，再按需要选择。使用 API 的插件不要求先安装桌面版。

## 本版改进

- 桌面版和浏览器插件拆分为两个包，移除桌面网页界面壳和捆绑的浏览器内核。
- 来源选择、聊天、笔记、记忆和设置整合到原生右侧学习栏；取消选文件不会丢失当前视频或草稿。
- 新选课程独立保存，同名课程也分开。续学已有课程从视频库选择；窗口标题变化时先停止记录，避免混入其他视频。
- 原文先概括，再进入问答上下文。图片问答真正读取本次授权的原图，可打开实际图片引用核对。
- 知识画面筛选保留板书、图示、公式和操作，纯讲者与片头片尾可过滤，原图不删除，可手动恢复。
- 已有本机智能体服务可以直接复用；配对不一致时给出连接入口，不会返回错误令牌或重复启动服务。
- 增加原生记忆编辑、锁定、版本回看、所选视频导出和旧版资料导入。
- 界面支持简体中文、繁体中文和英文，并按语言调整智能体与服务商顺序；部分动态提示还在补齐翻译。
- 离线计算组件改为选择档位后下载，显卡优先，可自动降级到 CPU。保留应用更新提醒与反馈入口。

## 旧版资料

浏览器插件的学习资料仍保存在原浏览器。原生桌面使用独立 SQLite 数据库，旧版 IndexedDB 不删除；可先从旧版导出资料，再在原生视频库导入。目前尚未完成全部旧聊天的自动迁移。

## 当前范围与反馈

当前项目仍是 **BETA 测试版，还不够完善**。系统文字识别可能误读小字、低清画面和公式，AI 笔记应保留不确定性，重要内容请打开原图核对。窗口采集显示的是记录时间，不能自动当作课程播放器进度。

原生版暂未迁移 Notion 同步和 AI 网页渠道，相关原有能力仍在浏览器插件中。Android、TTS、听视频 ASR 尚未实现，iPhone 暂缓。Apple/AMD 实机、全部平台账号和网页全屏、物理空白 Windows 仍未全部验收。应用内课程网页仅使用系统已有 WebView2；缺少该组件时可用本地视频或外部课程窗口。
